## 常见问题 / FAQ

### 为什么计时器在后台会停止？
请确保在系统设置中为 Isle Focus 开启后台刷新权限。

### 如何重置当日统计数据？
进入设置页面，向下滑动并点击"重置今日数据"即可。

### 应用耗电怎么办？
建议在设置中关闭"始终显示计时器"选项以节省电量。
